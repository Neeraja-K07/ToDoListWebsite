🐾 ToDo List Website 
A cute, colorful, and fully-featured productivity web app that helps you stay on track with your daily tasks, calendar events, and habit goals — all in one place!

✨ Features

✅ ToDo List Manager

➕ Add new to-do items with a click.
🖊️ Update existing tasks to keep them current.
✏️ Edit task content and priority anytime.
❌ Delete completed or unnecessary tasks.
📆 Calendar-wise Event Display

📅 View events on a calendar grid.
⭐ Dates with events are marked with stars.
🔘 Clicking a date shows all events below the calendar.
🗑️ Delete individual events with a single click.
📈 Daily Habit Tracker

📋 Track daily habits like exercise, reading, or meditation.
🌱 Automatically updates streaks if all habits are completed.
🔁 Habits reset at 11:59 PM each day for fresh tracking.
🚀 Getting Started

⚙️ Prerequisites

Python 3.x
Flask
SQLite (no installation needed — built-in)
JavaScript (for calendar interactivity)
HTML
CSS
